# 問名堂 交接文件

台灣廟口算命攤風格的姓名解讀網站。純靜態網站，所有計算都在瀏覽器裡完成，不需要後端。

- 目前預覽：https://claude.ai/artifact/Y9MReDmNgs2oMY5J3Rxqvd（Claude artifact，私人）
- 設計文件：https://claude.ai/artifact/V2vQpJYr4PV2TCeCo7ZDad

## 一、業主明確指示過的要點

### 產品
1. 獨立的新網站，和塔羅站「德爾菲神諭」分開。技術沿用塔羅站：GitHub Pages、規則式解讀引擎，DeepSeek 細說為選配。
2. 輸入姓名、乾坤（男命／女命），生辰為選填。網站產出解讀，名字不佳時提供改名建議。
3. 命理知識要查專業資料，解讀引擎要完整。有給生辰時，引擎要有相應變化，解讀更深入。
4. 取名字庫要夠大。業主嫌 363 字太少，現在是 1,785 字。
5. 解讀分成兩層：白話，以及非白話（文言批語）。

### 風格與美術
6. 中國風／台灣風，選定「台灣廟宇算命攤」。美術很重要，素材要謹慎挑選。
7. **不要像素風**。業主一度傾向細緻像素，後來改變主意。
8. **介面外觀要用美術素材，禁止用原生 CSS（色塊、漸層）偷懶。**
9. 草稿和佔位框業主無法評估，UI 框架要用真素材做完整。篇幅大的部分先做素材。
10. 字體要依用途挑選，不必全站同一種，而且要好讀。寫在紅紙上的名字尤其要清楚。
11. 文字放在素材上要搭配，不能歪、不能偏。**直排中文字要置中**（業主指出目前一直偏左）。
12. 要有簡單的特效、轉場和音效，增加互動感。手機上要流暢，不能卡頓。
13. 老師傅「點頭」表情原本是咧嘴大笑，業主覺得怪，已換成閉嘴微笑。

### 版面與文字
14. 以手機為主設計，桌機、筆電也要 RWD。
15. 破版、跑版要細修。
16. 用語要像真的台灣算命先生，不能出戲。例如原本的「生辰帶了嗎」就被業主點名突兀。
17. 業主授權自行上網查證並做決定，不必事事詢問（原話「去做，不要問我」）。但品質要專業、要認真做。

## 二、現況與重要事實

### 檔案結構（site/）
- `index.html`：舞台、頂列、操作區、開場畫面。
- `css/main.css`：全部樣式。開頭註解寫了設計原則。
- `js/main.js`：流程。入座 → 報名 → 乾坤 → 生辰 → 問事 → 數筆畫 → 批命 → 改名／對照。
- `js/engine/`：引擎。`chars` 康熙筆畫、`wuge` 五格、`bazi` 八字與真太陽時、`analyze` 評分、`reading` 兩層解讀、`rename` 改名。
- `js/data/`：字庫、81 數理、三才、生肖字根、取名字庫、人名語料。
- `js/fx.js`：特效（粒子、表情淡入、逐字出現、浮起動畫）。
- `js/sfx.js`：音效。全部用 WebAudio 即時合成，沒有音檔。
- `js/ai.js`、`js/config.js`：DeepSeek 細說。`AI_ENDPOINT` 目前是空的，所以「請先生細說」按鈕會隱藏。
- `vendor/lunar.js`：農曆與節氣（MIT）。
- `NOTICE.txt`：資料來源與授權。

### 引擎規則
- 筆畫：康熙字典。用 Unihan 的 kRSKangXi 計算，偏旁還原為本字；數字字依數值計。
- 五格：單姓上加 1、單名下加 1；外格用虛筆結構法；超過 81 減 80。
- 81 數理：劍靈表為主，並對照大紀元表，有爭議的數已標記。
- 三才：兩表取平均。
- 八字：以節氣換月、立春換年，用真太陽時（含台灣日光節約時間），預設子初換日。喜用神用扶抑、調候、專旺／從格判斷。
- 生肖字根：以三合、六合為喜，六沖、六害為忌。
- 評等界線：90／78／62／48 分，對應上上／上／中／中下／下。

### 美術素材（site/assets/，共 22 張）
- 全部用 Recraft 生成，水粉插畫風。場景套自訂風格「問名堂 廟埕水粉」（style id `098f36a0-a657-45a2-b36b-7385a355de11`）。材質和元件不套這個風格，因為套了會被畫成廟埕場景。
- 老師傅五種表情，都是用 nano banana 從同一張原圖改出來的，五張共用同一個裁切框。
- 面板與按鈕用 `border-image` 九宮格，紙張和木頭用平鋪材質。
- 後製腳本 `art/tools/process.py` → `process2.py` → `process3.py`，要依序執行。這些腳本不在 site/ 內，見下方「開發檔案」。
- Recraft 剩餘點數約 600。

## 三、未完成與已知問題（依優先順序）

1. **直排字偏左（業主指出）。**
   - 原因：霞鶩文楷上下高度不對稱，直排時瀏覽器以字型高度置中，所以名字紅紙、招牌、乾坤木牌、印章的字都偏左。
   - 修法：改成每個字橫排、往下堆疊（`writing-mode: horizontal-tb` 加直向 flex，或寬 1em 逐字換行），或改用直排度量正確的字型。
2. **紅紙、招牌、木牌、匾額、評等大字的字型（業主說不合適）。**
   - 已比較過，決定改用思源宋體 TC Black，標題與按鈕用 Bold。
   - 切片已做好，放在 `fonts/song/` 和 `fonts/song.css`（family 名稱 `WM Song`，字重 700／900），授權檔是 `fonts/NotoSerif-OFL.txt`。
   - **但還沒接進 index.html 和 css。**
3. 音效沒有實機試聽，音量和音色都需要調。
4. 手機流暢度沒有實機驗證。已經移除大部分陰影濾鏡、混色模式和持續動畫，粒子也降到每秒 30 格。
5. 「上回批命」清單和改名條件頁還是樸素的木牌選項。
6. DeepSeek 細說還沒接：要部署 Cloudflare Worker，再填 `js/config.js`。
7. 還沒部署到 GitHub Pages，目前只有 artifact 預覽。
